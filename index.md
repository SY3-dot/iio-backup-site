IIO Backup

IIO Backup is a private backup utility for the Investment Intelligence OS project.

It uses Google Drive to store encrypted database backups for disaster recovery.

The application is intended for personal use only and is not offered as a public service.

Data Access

IIO Backup requests Google Drive access to create and manage its own encrypted backup files.

It does not require access to unrelated personal files in Google Drive.
